## О проекте

IT Chat — кроссплатформенное приложение для общения и совместной работы. Пользователи могут находить контакты, вести личные и групповые переписки, видеть присутствие собеседников и работать с общими досками задач.

## Возможности

- регистрация и вход через Firebase Authentication;
- личные и групповые чаты в реальном времени;
- индикатор набора текста, статусы присутствия и прочтения сообщений;
- контакты, профили пользователей, аватары и блокировка;
- роли и уровни доступа участников группы;
- доски задач с колонками, drag-and-drop и назначением исполнителей;
- дедлайны, to-do списки и изображения задач в base64;
- персональные фоны досок;
- адаптивный интерфейс для web и мобильных устройств;
- светлая и тёмная темы.

- **Flutter / Dart** — интерфейс и бизнес-логика;
- **Firebase Authentication** — регистрация и авторизация;
- **Cloud Firestore** — сообщения, контакты, группы и задачи в реальном времени;

- **Firestore Security Rules** — контроль доступа к данным;
- **Shared Preferences** — локальные настройки приложения;
- **File Picker + base64** — загрузка аватаров, изображений и фонов.

## Локальный запуск

1. Установите Flutter SDK.
2. Скопируйте `.env.example` в `.env` и укажите параметры своего Firebase-проекта.
3. Установите зависимости и запустите приложение:

```bash
flutter pub get
flutter run -d chrome --dart-define-from-file=.env
```

Для production-сборки:

```bash
flutter build web --release --dart-define-from-file=.env
```

## Конфигурация Firebase

Приложению необходимы Firebase Authentication и Cloud Firestore. Правила доступа находятся в [`firestore.rules`](firestore.rules). Реальные ключи Firebase не хранятся в репозитории и передаются через `.env` при сборке.
